# Excel MCP Manager — Протокол Changelog

Полное описание структуры, правил ведения и шаблонов для листа "Changelog".

---

## Структура таблицы

Лист "Changelog" содержит таблицу со следующими столбцами:

| # | Колонка | Столбец | Тип данных | Обязательный |
|---|---|---|---|---|
| 1 | Version | A | Текст | да |
| 2 | Date | B | Дата (YYYY-MM-DD) | да |
| 3 | Author | C | Текст | да |
| 4 | Change Type | D | Текст (enum) | да |
| 5 | Sheet | E | Текст | да |
| 6 | Description | F | Текст | да |

### Детали по полям

**Version** (колонка A)
- Формат: `v{release}.{revision}`, например `v1.4`
- Соответствует версии файла, в котором сделано изменение

**Date** (колонка B)
- Формат: `YYYY-MM-DD`, например `2026-04-04`
- Дата выполнения изменения

**Author** (колонка C)
- Имя инициатора изменений
- **Обязательно уточнить у пользователя** перед первой записью в сессии: «Кто является автором/инициатором этих изменений?»
- Использовать полученное имя во всех записях текущей сессии

**Change Type** (колонка D)
- Допустимые значения: `DATA`, `STRUCTURE`, `FORMAT`, `FORMULA`
- Только заглавными буквами
- Один тип на запись; при нескольких типах — несколько записей или выбрать приоритетный

**Sheet** (колонка E)
- Имя листа, в котором сделано изменение
- Если затронуто несколько листов — перечислить через запятую или использовать `(несколько)`
- Если изменение касается книги целиком — `(вся книга)`

**Description** (колонка F)
- Краткое описание на русском языке
- Максимум 200 символов
- Конкретно: что именно изменено, какие данные, зачем

---

## Значения Change Type

### DATA
Изменение содержимого ячеек без изменения структуры документа.

Применять при:
- Обновлении значений ячеек
- Добавлении строк с данными
- Удалении строк с данными
- Заполнении пустых ячеек

### STRUCTURE
Изменение структуры книги или листов.

Применять при:
- Создании нового листа
- Удалении листа
- Переименовании листа
- Копировании листа
- Создании таблицы (`create_table`)
- Создании сводной таблицы (`create_pivot_table`)
- Создании диаграммы (`create_chart`)
- Вставке/удалении столбцов

### FORMAT
Изменение внешнего вида ячеек без изменения данных.

Применять при:
- Изменении шрифта, цвета, размера
- Изменении заливки ячеек
- Изменении границ
- Объединении/разъединении ячеек
- Изменении числового формата

### FORMULA
Добавление или изменение формул в ячейках.

Применять при:
- Добавлении новой формулы
- Изменении существующей формулы
- Удалении формулы (замене на значение)

---

## Правила ведения Changelog

1. **Append-only**: никогда не редактировать, не удалять, не перемещать существующие записи
2. Новые записи добавляются **в конец** таблицы
3. Имя автора уточняется у пользователя перед первой записью в сессии; одно и то же имя используется для всех записей сессии
4. Одна операция = одна запись (допускается несколько записей за одну сессию)
5. Если лист "Changelog" отсутствует — создать автоматически (см. шаблон ниже)
6. Лист "Changelog" **не версионируется сам по себе** — его наличие обязательно в каждой версии

## Примеры записей

### DATA — обновление значения ячейки
```
["v1.4", "2026-04-04", "{автор}", "DATA", "Данные",
 "Обновлено значение ячейки B5: изменён плановый показатель с 1500 на 1750"]
```

### DATA — добавление строк
```
["v1.5", "2026-04-04", "{автор}", "DATA", "Сотрудники",
 "Добавлены 3 новые строки с данными сотрудников: Иванов, Петров, Сидорова"]
```

### STRUCTURE — новый лист
```
["v2.0", "2026-04-04", "{автор}", "STRUCTURE", "Аналитика",
 "Создан новый лист 'Аналитика' для хранения агрегированных показателей"]
```

### STRUCTURE — создание таблицы
```
["v2.0", "2026-04-04", "{автор}", "STRUCTURE", "Данные",
 "Диапазон A1:E50 преобразован в именованную таблицу 'ТаблицаДанных'"]
```

### STRUCTURE — создание диаграммы
```
["v3.0", "2026-04-04", "{автор}", "STRUCTURE", "Сводная",
 "Создана столбчатая диаграмма 'Продажи по регионам' на основе A3:C15"]
```

### FORMAT — форматирование заголовков
```
["v1.6", "2026-04-04", "{автор}", "FORMAT", "Отчёт",
 "Применено форматирование заголовков: синий фон, белый жирный шрифт, диапазон A1:F1"]
```

### FORMAT — объединение ячеек
```
["v1.7", "2026-04-04", "{автор}", "FORMAT", "Отчёт",
 "Объединены ячейки A1:F1 для заголовка раздела"]
```

### FORMULA — добавление формулы
```
["v1.8", "2026-04-04", "{автор}", "FORMULA", "Данные",
 "Добавлена формула =SUM(B2:B100) в ячейку B101 для подсчёта итога по столбцу"]
```

### FORMULA — обновление формулы
```
["v1.9", "2026-04-04", "{автор}", "FORMULA", "Данные",
 "Обновлена формула в G2:G50 — добавлено условие проверки через IFERROR"]
```

### Множественные изменения за одну сессию
```
["v2.1", "2026-04-04", "{автор}", "DATA",      "Продажи",  "Добавлены данные за март 2026 (строки 102-134)"]
["v2.1", "2026-04-04", "{автор}", "FORMAT",    "Продажи",  "Форматирование новых строк: чередование фона"]
["v2.1", "2026-04-04", "{автор}", "FORMULA",   "Сводная",  "Обновлена формула итога для включения марта"]
```

## Шаблон создания нового листа Changelog

Если лист "Changelog" отсутствует, выполнить следующую последовательность:

### 1. Создать лист
```
mcp__excel__create_worksheet(
  filepath="...",
  sheet_name="Changelog"
)
```

### 2. Записать заголовки
```
mcp__excel__write_data_to_excel(
  filepath="...",
  sheet_name="Changelog",
  start_cell="A1",
  data=[["Version", "Date", "Author", "Change Type", "Sheet", "Description"]]
)
```

### 3. Отформатировать заголовки
```
mcp__excel__format_range(
  filepath="...",
  sheet_name="Changelog",
  range="A1:F1",
  format={
    "font": {"bold": true, "color": "FFFFFF"},
    "fill": {"color": "1F4E79"},
    "alignment": {"horizontal": "center", "vertical": "middle"}
  }
)
```

### 4. Записать первую запись (строка 2)
```
mcp__excel__write_data_to_excel(
  filepath="...",
  sheet_name="Changelog",
  start_cell="A2",
  data=[["v1.0", "YYYY-MM-DD", "{автор}", "STRUCTURE", "(вся книга)",
         "Создан лист Changelog для отслеживания изменений документа"]]
)
```

## Определение номера следующей строки

Перед добавлением записи прочитать текущее состояние Changelog:

```
mcp__excel__read_data_from_excel(
  filepath="...",
  sheet_name="Changelog",
  range="A1:A1000"
)
```

Найти первую пустую строку после последней записи — это и будет `next_row`.

Альтернативно: прочитать только первый столбец небольшого диапазона, подсчитать непустые строки, добавить 1.

## Ширина столбцов (рекомендации)

После создания Changelog применить `format_range` для установки ширины столбцов:

| Столбец | Рекомендуемая ширина |
|---|---|
| A (Version) | 10 символов |
| B (Date) | 14 символов |
| C (Author) | 10 символов |
| D (Change Type) | 14 символов |
| E (Sheet) | 20 символов |
| F (Description) | 60 символов |

Установить `wrap_text: true` для столбца F (Description).
